## 미확인·한계

- **본인 확인 없음.** 이 문서의 모든 결과는 AI 실행 범위다. 확인 방법은 [실행법의 "직접 확인할 것"](../n08-web-client.md)에 있다.
- 브라우저 화면 확인은 Claude 내장 브라우저로 했다. 사람이 눈으로 보는 확인은 남아 있다.
- README가 `확인 필요`로 남긴 "WSL 서버에 Windows 쪽 웹앱이 접속되는지"는 시도하지 않았다. 같은 컨테이너에서 백엔드와 서버를 함께 실행해 우회했다.
- 서버가 순차 처리이고 수신 중 유휴 제한이 없어서, 동시 접속과 부하는 측정하지 않았다. 직렬화와 대기 한도는 가짜 서버로만 확인했다.
- 명세는 사람이 README에서 옮긴 것이다. 분석으로 복원한 명세에 대한 동작은 확인하지 않았다(N12).
- 다른 PC(Mac arm64 등)에서의 재실행, 호스팅·공개 URL(N20)은 하지 않았다.
- 블라인드 규칙: N10 자료와 본 실험의 정답·기준 명세·숨은 평가 입력은 찾거나 열지 않았다. 저장소는 `main` 브랜치만 받았다.

## 재실행

저장소 루트 PowerShell에서(이미지·서버 빌드는 [실행법](../n08-web-client.md) 1~2번):

```powershell
docker compose -f compose.n05.yaml run --rm n05 node --test --test-timeout=120000 "web/test/*.test.mjs"
docker compose -f compose.n08.yaml up -d --wait
# 브라우저 http://127.0.0.1:8080 에서 1 2 3 전송, 평가 실행
docker compose -f compose.n08.yaml exec n08 sh -c 'python3 scripts/n07-evaluate.py --cases practice/n06/cases.json --target 127.0.0.1:19006 --out runs/n08/eval-cli-$(date +%Y%m%d-%H%M%S).json'
docker compose -f compose.n08.yaml down
```

기대 결과: 테스트 `tests 51, pass 51, fail 0`. 화면 `합계 = 6`. 평가 `21/21`, `all_pass true`, 명령줄은 종료 코드 0. `down` 뒤 컨테이너 없음.
